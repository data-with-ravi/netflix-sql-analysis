# Netflix SQL Data Analysis

## Project Overview

This project analyzes the Netflix titles dataset using MySQL.

## Analysis Performed

- Movies vs TV Shows
- Titles by release year
- Titles added by year
- Ratings analysis
- Country analysis
- Genre analysis
- Movie duration analysis
- TV Show seasons analysis
- Top directors
- Top actors
- Movie and TV Show comparisons

## Tools Used

- MySQL
- SQL
- GitHub

## Dataset

Netflix titles dataset containing information about movies and TV shows, including title, type, director, cast, country, release year, rating, duration, and genres.

## Key Findings

- Total titles: 8,807
- Movies: 6,131 (69.62%)
- TV Shows: 2,676 (30.38%)
- Earliest release year: 1925
- Latest release year: 2021
- Most common rating: TV-MA (3,207)
- Top country: United States (3,690)
- Most common movie duration: 90 minutes (152 movies)
- Average movie duration: 99.58 minutes
- Peak year for titles added: 2019 (2,016 titles)
